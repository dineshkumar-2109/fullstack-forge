# Changelog

## 1.0.0
- Accounts: sign up, sign in, sign out, 14-day sessions, data export, account deletion.
- Projects: create, rename, delete (cascades), unique names per user, task counts.
- Tasks: create with optional due date, status workflow, filters, optimistic concurrency, overdue highlighting.
- Platform: validated config, JSON logs with redaction, request IDs, security headers, CSRF origin checks,
  rate limiting, body limits, health/readiness, graceful shutdown, migrations, seed, Docker, CI.
